# DroidDeploy Android SDK

Android SDK for deploying and managing builds via remote server.

## Installation

Add JitPack repository and the DroidDeploy dependency to your project:

### Gradle (Kotlin DSL)

```kotlin
repositories {
    google()
    mavenCentral()
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    implementation("com.github.pashaoleynik97:droiddeploy:0.1.0")
}
```

### Gradle (Groovy DSL)

```groovy
repositories {
    google()
    mavenCentral()
    maven { url 'https://jitpack.io' }
}

dependencies {
    implementation 'com.github.pashaoleynik97:droiddeploy:0.1.0'
}
```

## Requirements

- **Min SDK:** 29 (Android 10+)
- **Compile SDK:** 35
- **Java Version:** 11+
